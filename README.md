# DSA

My C++ solutions to a custom-modified [Striver A2Z](https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet?page=sheet) DSA sheet, organized by topic.

## Track my progress

I built my own tracker for this sheet: **[Track Sheet](https://tracksheet-rehnx.vercel.app/)**. It's a full-stack web app (React, Supabase, Vercel) where I mark problems as done, to do or skipped, and it shows streaks and a year-long activity heatmap. You can use it with the built-in DSA sheet (518 problems) or upload your own.

Source code: [rehnx95/Track-Sheet](https://github.com/rehnx95/Track-Sheet)
