# DSA in C++

My C++ solutions to a custom-modified Striver A2Z DSA sheet, organized topic by topic.

## 📊 Track my progress

I built my own tracker for this sheet: **[Track Sheet](https://tracksheet-rehnx.vercel.app/)**. It's a full-stack web app (React, Supabase, Vercel) where I mark problems as done, to do or skipped, and it shows streaks and a year-long activity heatmap. The built-in DSA sheet has 518 problems, and you can also upload your own.

Source code: [rehnx95/Track-Sheet](https://github.com/rehnx95/Track-Sheet)

## ▶️ Run a solution

```bash
git clone https://github.com/rehnx95/DSA.git
cd DSA
g++ -std=c++17 "path/to/solution.cpp" -o solution
./solution
```
